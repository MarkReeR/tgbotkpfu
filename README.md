# Telegram Bot KPFU

Бот для просмотра расписания КФУ на Go.

## Возможности

- Просмотр расписания на сегодня по команде `/schedule`
- Привязка группы командой `/bind <номер_группы>`
- Настройка ежедневных уведомлений через `/settings`
- Уведомления приходят за час до первой пары
- Данные о привязке пользователей к группам сохраняются в файл (не теряются после перезапуска)

## Структура проекта

```
/workspace
├── cmd/bot/main.go           # Точка входа
├── internal/
│   ├── config/               # Конфигурация
│   ├── handler/              # Обработчики команд Telegram
│   ├── models/               # Модели данных
│   ├── repository/           # Репозиторий (хранение в файле)
│   └── service/              # Бизнес-логика
├── pkg/schedule/             # Парсер расписания
├── .env.example              # Пример конфигурации
├── Dockerfile                # Docker образ
├── go.mod                    # Зависимости Go
└── README.md                 # Этот файл
```

## Запуск

### Локально

1. Скопируйте `.env.example` в `.env` и заполните переменные:
   ```
   BOT_TOKEN=your_bot_token_here
   DB_PATH=bot_data.db
   ADMIN_ID=0
   ```

2. Запустите бота:
   ```bash
   go run ./cmd/bot/main.go
   ```

### В Docker

```bash
docker build -t tgbotkpfu .
docker run --env-file .env tgbotkpfu
```

## Команды бота

- `/start` - Приветствие и справка
- `/bind <группа>` - Привязать группу (например, `/bind ИВТ-1-21`)
- `/schedule` - Показать расписание на сегодня
- `/settings` - Настройки уведомлений

## Формат расписания

Расписание выводится в формате:
```
Суббота [в]
——————————————————————
⏰ 8:00 - 9:30
📚 Предмет 1 (ИВТ-1-21)
📍 Ауд. 101

⏰ 9:45 - 11:15
📚 Предмет 2 (ИВТ-1-21)
📍 Ауд. 102
```

## Оптимизации

- Использование `sync.RWMutex` для потокобезопасного доступа к данным
- Сохранение данных в JSON-файл после каждого изменения
- Эффективное форматирование строк через `strings.Builder`
- Graceful shutdown при получении сигналов SIGINT/SIGTERM
